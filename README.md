# Shamim Reza — Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript.

## Before deploying

1. Replace every `https://github.com/` placeholder with the real repository URL.
2. Replace the LinkedIn URL.
3. Replace `your.email@example.com`.
4. Put your CV at `assets/Shamim_Reza_CV.pdf`.
5. Update project descriptions/technologies if needed.

## Deploy with GitHub Pages

1. Create a GitHub repository, e.g. `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your live portfolio URL.

No backend is required.
